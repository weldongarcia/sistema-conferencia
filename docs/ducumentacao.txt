1. Visão Geral

O sistema de conferência de recebimento tem como objetivo controlar e validar mercadorias recebidas através da conferência de notas fiscais, volumes logísticos e itens contidos nas caixas.

O sistema é composto por três componentes principais:

Backend (API) responsável pela lógica de negócio.

Painel Web para gestão e monitoramento das conferências.

Aplicativo Android (coletor) utilizado pelos operadores para realizar a conferência física das mercadorias.

3. Estrutura Logística do Sistema

O sistema trabalha com três níveis principais:

Nota Fiscal
      ↓
NP (Número do Pedido Logístico)
      ↓
Volumes (caixas)
      ↓
Itens dentro do volume
Observações

Uma NP pode ter várias notas fiscais.

Notas diferentes podem compartilhar a mesma NP.

4. Tipos de Etiquetas
4.1 Etiqueta Branca

Contém:

Número da NP

Número do volume

Código de barras

Exemplo:

NP: 11235071
VOL: 0015

Utilizada para identificar a caixa no sistema.

4.2 Etiqueta Amarela

Contém a relação dos produtos dentro da caixa.

Utilizada para identificação física do conteúdo.

5. Tipos de Caixas
5.1 Caixa Fechada

Caixa padrão enviada pelo fornecedor.

Exemplo:

1 caixa = 50 unidades
Regras

Ativar modo embalagem

Quantidade automática

Não precisa validar volume

5.2 Caixa Fracionada

Caixa aberta ou com quantidade diferente da embalagem padrão.

Regras

Desativar modo embalagem

Quantidade digitada manualmente

Volume precisa ser validado

6. Modos de Registro de Item

O sistema permite dois tipos de registro.

Registro Bipado

Produto registrado via leitura do código de barras.

tipo_registro = bipado
Registro Digitado

Quantidade informada manualmente.

tipo_registro = digitado
7. Divergências de Conferência

O sistema identifica automaticamente divergências entre:

itens da nota fiscal

itens conferidos

Tipos de divergência
Tipo	Descrição
Falta	NF possui item que não foi conferido
Sobra	Quantidade maior que NF
Item incluído	Produto não existente na NF
Item não contado	Item da NF não registrado
8. Irregularidades Logísticas

O sistema permite registrar irregularidades físicas.

Tipos:

falta em volume fracionado
falta em volume fechado
sobra em volume fracionado
volume faltando
volume de outro estabelecimento
avaria

Cada irregularidade pode conter:

produto

volume

quantidade

observação

foto

indicação de caixa violada

15. Métrica de Acurácia

A acurácia da conferência é calculada com base nos itens corretos.

Fórmula:

Acurácia = itens corretos / total de itens

Exemplo:

Itens corretos: 19
Itens totais: 21

Acurácia = 90,48%
